> 一个面向财务管理专业学生的求职作品：左手个人财务数字化，右手AI产业链财务BP分析。
>
> 在线体验：<https://xingyueye419.github.io/AI-Finance-Assistant/>

***

## 项目背景

我是财务管理专业的本科生（2024级），对"AI + 财务"的交叉方向有强烈兴趣。

做这个项目的初衷有两个：

1. **解决自己的问题**：日常记账时，市面上的App要么广告太多，要么需要注册登录。我想要一个**打开就能用、数据存在本地、能导出备份**的纯净工具。
2. **验证所学知识**：课堂上学了财务分析、预算管理、现金流分析，想亲手做一个能把这些知识"落地"的东西。同时，AI算力是当前最热的赛道，我长期关注这个产业链，想把"财管专业视角"和"AI产业认知"结合起来，打造一个差异化的分析模块。

这个项目也是我找实习的**核心作品集**之一。

## 核心功能

### 模块一：个人财务助手

一个功能完整的记账工具：

- **收入/支出双轨录入**：支持自然语言输入（如"早餐8.5元"），自动提取金额
- **智能分类**：基于关键词自动分类（餐饮/购物/交通/娱乐/其他）
- **自定义日期**：支持补记历史账单， `input[type="date"]` 实现
- **预算管理**：设定月度预算，可视化进度条，超支预警
- **时间筛选**：今日/本周/本月/全部，一键切换
- **财务洞察**：基于结余率自动判断财务状况（规则引擎）
- **趋势图**：近7天支出折线图（Chart.js）
- **数据导出**：一键导出CSV，带BOM头支持中文Excel打开
- **数据持久化**：localStorage本地存储，隐私安全
- **财务金句**：8条精选金句，支持随机切换

### 模块二：AI算力产业链财务分析

**这是项目的差异化核心**，从"财务BP（业务伙伴）"视角切入AI算力产业链：

- **产业链全景**：从芯片设计 → HBM存储 → 晶圆制造 → 服务器制造 → 数据中心 → 云服务的完整链路
- **关键财务指标**：英伟达毛利率75%（2Q FY2027）、SK海力士83%（Q2 2026）、台积电67.7%（2Q 2026）、浪潮信息4.88%（2025年报）
- **毛利率对比**：六环节毛利率柱状图，直观展示产业链利润分配格局
- **ROE杜邦拆解**：英伟达（101.5%）、台积电（35.2%）、SK海力士（31.1%）、美光（\~22%）、AMD（7.8%）、浪潮信息（11.6%），拆解盈利能力×运营效率×财务杠杆
- **资本开支趋势**：四大云厂商（Alphabet/Amazon/Microsoft/Meta）2025实际 vs 2026E指引对比，合计同比增长约77%
- **现金流健康度评分**：芯片设计层 vs HBM存储层 vs 服务器制造层 vs 云服务层的五维对比评分
- **营运资本效率（CCC）**：现金转换周期拆解（DSO/DIO/DPO），横向柱状图对比台积电（76天）、英伟达（112天）、浪潮信息（116天）、SK海力士（129天），结合毛利率分析真实盈利质量
- **六大环节横向对比总表**：HBM存储、芯片设计、晶圆制造、数据中心、云服务、服务器制造六大环节的毛利率/ROE/CCC/现金流/综合评级对比表，含机会点、风险点与经营启示（财务BP视角）
- **财务BP方法论**：本质是帮老板配置稀缺资源——把有限的钱、精力、时间押注到ROI最高的地方，同时死守现金流，确保永远不下牌桌。用毛利率、CCC、现金流三把尺子，把"哪个环节好"的模糊判断变成"好在哪里、差在哪里、该怎么应对"的具体行动
- **银行端案例**：恒丰银行深圳分行AI算力产业链信贷投放案例，含"恒银E链"供应链金融产品分析，财务BP视角解读银行链式金融服务逻辑
- **交互式预算模型**：模拟算力企业的预算分解，调整营收、毛利率、资本开支占比等参数，实时计算EBITDA、自由现金流、FCF利润率（含输入校验）
- **行业趋势**：整合WAIC 2026智能财务论坛蓝皮书六大趋势
- **英伟达2Q FY2027财报亮点**：季度营收$962亿（同比+106%）、净利润$597亿（同比+126%）、数据中心收入$890亿（同比+117%），含黄仁勋"算力即营收"观点解读、GPU资产证券化分析、Vera Rubin量产动态
- **AI财务分析师（演示版）**：基于产业链数据的预设问答系统，涵盖英伟达ROE拆解、HBM高利润逻辑、浪潮信息低毛利原因等核心问题，完整版可接入大模型API

> 数据说明：产业链财务数据基于各公司公开财报及行业研究整理，用于分析演示。数据截至2026年8月，按季度跟随财报季更新。核心趋势参考上海国家会计学院《2026年中国企业财务智能化调查报告（蓝皮书）》。

## 项目亮点（面试时可展开讲）

### 1. "财管 + AI工具"的复合能力

不只是做一个记账工具，而是把专业所学（财务分析、预算管理、现金流分析）和关注领域（AI算力产业链），用AI工具实现成可运行的产品。

### 2. 从"个人财务"到"企业财务BP"的思维跃迁

模块一是C端个人理财，模块二是B端产业链分析。同一个产品里展示了两种财务思维：个人现金流管理 vs 企业资本配置效率。

### 3. 多维度财务分析框架

不只是展示数据，而是构建了一套完整的分析框架：毛利率定位 → ROE杜邦拆解 → 资本开支趋势 → 现金流健康度 → 营运资本效率（CCC） → 六大环节横向对比 → 交互式预算建模。每个维度都有图表可视化+财务BP视角的文字解读。

### 3.5 财务BP方法论：从"展示数据"到"输出判断"

项目不是数据看板，而是构建了完整的分析闭环：**数据 → 对比 → 机会/风险识别 → 经营启示 → 方法论**。核心是"三把尺子"——毛利率（定价权）、CCC（运营效率）、现金流（盈利质量），把"哪个环节好"的模糊判断变成"好在哪里、差在哪里、该怎么应对"的具体行动。这正是财务BP区别于普通数据分析师的本质：不对外输出投资建议，而是对内输出经营决策支持。

### 4. 产业链+供应链金融视角

不只分析产业链本身，还引入银行端案例（恒丰银行），展示对供应链金融"恒银E链"产品的理解——从产业链分析延伸到金融服务落地，体现财务BP的跨维度思考。

### 5. 信息整合与快速迭代能力

借助AI助手追踪行业动态，收到信息后快速判断价值并整合进项目：WAIC 2026蓝皮书发布后2天完成整合，恒丰银行案例当天获取当天更新进项目。核心能力不在于"最先看到信息"，而在于**拿到信息后能判断该不该加、怎么加、用什么分析框架拆解**。

### 6. 工程上的取舍意识

- 砍掉语音输入、Agent接入、APP版等"看起来很酷但和核心目标无关"的功能
- 坚持单文件架构，降低部署和维护成本
- 所有数据本地存储，零后端依赖

## 数据更新机制

- **更新频率**：按季度跟随财报季更新（一年4次）
- **更新标准**：只加入能用现有分析框架拆解的内容，通过"三问测试"：
  1. 能否套进现有分析框架？
  2. 是否展示新的财务分析维度？
  3. 是否来自可靠的官方信息源？
- **数据来源优先级**：公司官方公告 > 投资者互动平台 > 券商研报 > 财经媒体报道 > 自媒体分析
